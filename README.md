

# 短视频后端API服务器

2026-01-01

## 业务模块
- AUTH - 验证中心，用户登录状态，登录方式有短信验证码/邮箱验证码/账号密码/微信/谷歌/苹果/QQ/FB/.. ，未注册的用户登录即注册，系统会构造一个初始化的【用户资料】存储，并返回验证信息给客户端保存，使用双Token验证机制，临时Token使用jwt快速比对。

- DYNAMIC - 动态 （朋友圈强化版）UGC内容，可以发送文字/照片/livephoto/视频/语音/商品..，动态可以带活动标签/地理坐标/活动信息/地址/，互动操作有浏览/点赞/评论/收藏/分享（转发）

- MUSIC - 音乐 搭配VIDEO模块使用，用户发布短视频的时候，会把原声部分提取单独构造一个MUSIC实体存储，其他用户发布短视频的时候可以使用这些音乐。进阶会提供音乐收藏/编排成专辑/推荐流/热门..等功能

- LIVE - 直播 通过审核的USER可以开通直播权限，可以开启直播，直播推流服务器使用第三方，单用户发布N个直播间，抛弃传统直播APP那种单一用户只能发布1个直播间的思想，除了推流直播间，还可以发布视频循环播放的视频直播间，直播间还有任务可以领取..

- VIDEO - 短视频 （核心功能）用户通过认证可以发布短视频，短视频支持浏览/点赞/评论/弹幕/收藏/分享/上热门/推荐/举报/购买..等互动操作，用户还可以创建ALBUM收藏特定的VIDEO，编排成任务关卡挂载到直播间，分享给别的用户。

- MARKET - 市场部 为了商用客户提供的市场部功能，内建有内部资产管理/产品管理系统，产品带展厅模式，才用声光电多维数据来展览产品特性。其中，还内置电商核心功能，支持产品快速上架线上销售，带订单/流程/地址簿/活动/优惠券等功能聚合，除了传统电商的常见功能之外，还增加了一个【产品集合】的模式，给产品选装包个性化定制，适合汽车/定制产品的灵活购买方式。

- WALLET - 钱包 （电商辅助功能），支持多币种/交易风控阻断隔离/交易号/币种转换汇率等，支持微信/支付宝/云闪付/贝宝/..充值/提现方式。



## 技术框架

- WEB - Actix 4.x 构建 传输层，仅负责路由/提取参数 等基础功能， 灵活切换框架也不会污染项目核心功能
- DB - PostgreSQL 16+ 免费开源功能强大的数据库
- CACHE - Redis 7+ 缓存
- SQLX - rust的关系数据库操作标准
- MONGODB - 日志追踪数据库
