# 🥤 可乐 短视频后端API服务器
**version**: 0.1.1
**更新日期**: 2026-06-12



---

## 📖 项目简介
这是一个使用 Rust 语言开发的 CMS 后台 Web 系统。
采用分层演进式架构，适配不同规模业务：
- 初期：单二进制可执行文件，目录简洁，部署简单
- 中期：多实例部署 + Nginx 分流，支撑中型网站并发
- 后期：按业务拆分微服务，分布式容灾部署，适配大型平台

---

## 🧩 业务模块
| 图标 | 模块 | 功能说明 |
| ---- | ---- | ---- |
| 🔐 | AUTH 验证中心 | 支持短信、邮箱、账号密码、微信、QQ、苹果等多方式登录；未注册用户登录即自动注册并初始化用户资料；采用双 Token 机制，JWT 快速校验临时凭证。 |
| 📸 | DYNAMIC 动态 | 强化版 UGC 内容广场，支持文字、图片、实况照片、视频、语音、商品等发布；可添加标签、地理位置；支持浏览、点赞、评论、收藏、分享等互动。 |
| 🎵 | MUSIC 音乐 | 配合短视频模块，自动提取视频原声生成独立音乐素材，供全站复用；支持音乐收藏、专辑、推荐流、热门榜单等功能。 |
| 🎥 | LIVE 直播 | 审核用户可开通直播权限；单账号支持创建多个直播间，包含实时推流、视频轮播直播间；内置直播间任务体系。 |
| 🎬 | VIDEO 短视频(核心) | 平台核心功能，认证用户可发布作品；支持浏览、点赞、弹幕、评论、收藏、分享、热门推荐、举报、付费等操作；可创建视频专辑并挂载至直播间。 |
| 🛒 | MARKET 市场/电商 | 面向商用场景，内置资产管理、产品多维展厅；集成完整电商能力：商品上架、订单、地址簿、活动、优惠券；支持产品组合选配，适配定制类商品售卖。 |
| 💰 | WALLET 钱包 | 电商配套模块，支持多币种、交易风控隔离、汇率换算；对接微信、支付宝、云闪付等，实现充值、提现全流程。 |

## 🛠️ 技术框架
| 技术组件 | 版本 | 用途 |
| ---- | ---- | ---- |
| 🌐 Web 框架 | Actix 4.12.x | 网络传输、路由分发、参数解析，业务与框架解耦，可灵活替换 |
| 🗄️ 主数据库 | PostgreSQL 16+ | 核心业务数据存储，开源稳定、功能完善 |
| ⚡ 缓存 | Redis 7+ | 热点数据缓存，提升接口响应速度 |
| 📊 数据库驱动 | SQLX | Rust 标准关系型数据库操作组件 |
| 📝 日志库 | MongoDB | 系统日志、行为追踪数据存储 |
